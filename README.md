# Хифз — трекер заучивания Корана

Приложение для заучивания новых сур и повторения выученного. Подходит любому человеку:
при первом запуске мастер настройки спрашивает, что вы уже знаете (суры целиком или частично — с какого по какой аят), как будете учить и по какому расписанию.

## Что умеет

**Текст, перевод, тафсир, аудио**
- Арабский текст всех 114 сур (6236 аятов) и перевод смыслов Кулиева встроены в приложение и работают без интернета.
  Шрифт мусхафа — KFGQPC Uthmanic Hafs.
- Тафсир Ибн Касира на русском загружается по суре из открытого проекта `spa5k/tafsir_api` (через jsDelivr)
  и кэшируется. Открывается кнопкой «тафсир» у аята или «Тафсир блока». Есть «Предыдущий»/«Следующий» и копирование.
- Чтецы: Айман Сувейд (по умолчанию), Мишари Рашид аль-Афаси, Абу Бакр аш-Шатри, Ясир ад-Даусари,
  Махмуд Халиль аль-Хусари. Аудио по аятам с everyayah.com.
- Повтор аята N раз, повтор всего блока N раз, пауза 1–5 секунд, скорость 0,75–1,25×,
  режим «слушай и повторяй» (после аята пауза такой же длины).

**Заучивание**
- Три шага для каждой суры: перевод, тафсир, хифз. Сура «заучена полностью», только когда отмечены все три.
- Медальон с номером суры растёт с каждым шагом: тафсир добавляет рамку, перевод — золотую звезду,
  хифз — зелёную сердцевину; все три вместе — полный медальон с венцом.
- Для больших сур выбирается диапазон «с аята … по аят …», и смысловые блоки строятся только по нему.
- Для сур 1, 18, 36, 55, 56 и 67–114 блоки заданы по темам (`static/data/themes.js`): у каждого — название и описание темы.
- Для остальных сур смысловые блоки рассчитываются автоматически: по смене рифмы окончаний аятов и словам, с которых начинается
  новая тема. Каждому блоку даётся краткое название. Можно менять название, границы, число аятов,
  делить и объединять блоки или пересчитать заново.
- Режим «Проверка» скрывает арабский текст и открывает по одному аяту; «Первые буквы» оставляет только первую букву каждого слова.

**Повторение и план**
- Интервальные повторы (по умолчанию 1, 3, 7, 14, 30 дней, можно задать свои).
- Манзиль: всё выученное делится на 7, 10 или 14 частей, близких по объёму текста. У каждого дня — галочка «повторено».
  Аль-Фатиха в манзиль не входит — её читают в каждом намазе.
- На главной: все блоки текущей суры и манзиль дня вместе со свежим повторением. На телефоне — нижняя навигация, окна открываются снизу.
- Дни уроков с устазом (на главной появляется список «что сдать») и дни без нового урока.
- Дневная норма (¼, ½ или 1 страница) и прогноз: когда закончите диапазон, суру и джуз.
- Процент заученного считается по страницам мединского мусхафа (604 стр.): для каждого джуза известно число страниц,
  а внутри джуза объём аята определяется его длиной. Так длинные и короткие аяты учитываются честно.

## Новое в версии 10 — новый дизайн

- **Главная**: шапка с иллюстрацией и аятом (15:9), карточка прогресса с кольцом и кнопкой «Продолжить»,
  «Сегодня — N задачи» (раскрывается списком), три плитки: текущая сура, повторения на сегодня, дни подряд.
  У текущей суры переключатель «Блоки / Весь текст».
- **Прогресс** (нажмите на кольцо с процентом): неделя / месяц / всё время, график выученных страниц,
  «Последние успехи», джузы и вехи.
- **Суры**: фильтры и поиск в рамке, вид списка — за значком настроек; строки с полосой прогресса.
- **Страница суры**: тёмно-зелёная шапка с медальоном и арабским названием, закладка «на главной»,
  три кнопки «Перевод / Тафсир / Хифз». **Удержание «Тафсир» открывает тафсир всей суры.**
- **Манзиль → Тренировка**: случайный аят по сурам или джузам (только выученное или всё),
  «Откуда этот аят?» — открыть суру, перевод, следующий аят, аудио; вкладка «Проверить себя».
- **Журнал уроков**: число уроков, средняя и последняя оценка, график оценок, распределение 5/4/3/2.

## Новое в версии 8

- **Новая иконка приложения** (корона на вершине пути): `static/icons/` — 512, 192, 180 (iPhone) и 32 px (вкладка браузера).

- **Смысловые блоки для сур 1–29** — по страницам мединского мусхафа (из присланного файла); у блока видна страница.
  Теперь тематическое деление есть для сур 1–73 и 74–114.
- **Блок на главной открывается на месте** — без перехода во вкладку «Суры».
- **Выученную суру можно оставить на главной** (на экране завершения или на странице суры): компактная строка,
  по нажатию раскрываются её блоки.
- **Новое выученное входит в манзиль со следующей недели.** В течение недели деление манзиля не меняется;
  на вкладке «Манзиль» видно, что и с какого дня добавится («сейчас» — добавить сразу).
- **Урок с устазом**: оценка 2–5, несколько сданных сур, домашнее задание — какие суры выучить и какие повторить.
  В день следующего урока задание появляется на главной; выученное из задания отмечается галочкой.
  Если дни уроков не заданы, задание видно на главной всегда.
- **Текст суры**: на странице суры переключатель «Блоки / Текст» — сура целиком, арабский текст и перевод подряд.
- **Разделить на блоки** всю суру или её часть: по смыслу или поровну (по N аятов).

## Новое в версии 7

- **Раздела «Повторы» больше нет — всё в Манзиле.** В карточке «Манзиль» на главной сначала идёт «Свежее»
  (недавно выученное по интервалам, с оценками «Легко / С запинками / Забыл»), затем часть манзиля на сегодня,
  слабые места и «проверить себя». На вкладке «Манзиль» — та же карточка «Свежее» над кругом дней.
- **«+ слово» у каждого аята.** В режиме «Проверка» у каждого скрытого аята свои маленькие кнопки:
  «+ слово» открывает следующее слово этого аята, «аят» — весь аят. Внизу блока — «открыть все» и «скрыть снова».
- **Якорь для каждого аята.** В открытом блоке — цепочка первых слов всех его аятов с номерами;
  нажатие переносит к аяту. В «Изменить» каждому аяту можно задать своё слово-якорь.

## Новое в версии 6

- **Хизбы и четверти**: разметка 60 хизбов и 240 четвертей (руб‘ аль-хизб). Манзиль можно делить «по объёму» или «по хизбам» — тогда дни начинаются и заканчиваются на метках ۞.
- **Список сур**: три режима — джузы, суры, хизбы (с четвертями и прогрессом каждой) — и порядок 1 → 114 или 114 → 1.
- **Отметка отдельных аятов**: нажмите на номер аята в открытом блоке — большой блок можно учить по частям.
- **Завершение суры**: экран с медальоном, дуа, итогом («выучено за N дней») и выбором следующей суры.
- **Мастер настройки по джузам**: отметьте джузы целиком или раскройте джуз и отметьте суры, в том числе частично.
- **Выученные блоки свёрнуты** на главной в одну строку «Выучено: аяты …».
- **О суре**: период ниспослания (условно), место в порядке ниспослания и краткие обстоятельства ниспослания для известных случаев.
- **Отметка отдельных сур в манзиле**: день закрывается сам, когда отмечены все суры.
- **Шапка суры при прокрутке**: название и номер текущего блока.
- **Приложение помнит экран**: открытый блок, место прокрутки и последняя открытая сура сохраняются при переключении вкладок и перезапуске.
- **Размер кнопок и текста** (обычный, крупный, очень крупный) и **высокий контраст** — в Настройках → Текст.

Данные о хизбах и порядке ниспослания — в `static/data/meta.js` (по открытым данным Tanzil).

## Новое в версии 5

- **Самопроверка связок** («Манзиль → проверить себя»): какой аят идёт дальше, с чего начинается следующий блок, какая сура идёт после. Забытое попадает в слабые места.
- **Установка на телефон и работа без интернета** (PWA): иконка на главном экране, приложение открывается офлайн. Аудио блока можно скачать заранее («скачать аудио» в открытом блоке).
- **Три оценки повтора**: «Легко» — интервал через ступень, «С запинками» — тот же интервал, «Забыл» — завтра и в слабые места.
- **Слабые места**: забытое при повторе, замечания устаза и ошибки самопроверки собираются в один список.
- **Пропущенный день манзиля**: вчерашнюю часть можно добавить к сегодняшней, сдвинуть круг, отметить или пропустить.
- **Тематические блоки для сур 30–114** (и 1, 18) с описанием темы каждого блока.
- **Постепенное скрытие слов**: каждое пятое → третье → второе → всё; нажмите на пропуск, чтобы подсмотреть.
- **Запись своего чтения**: микрофон у аята, затем «сравнить» — сначала чтец, потом ваша запись. Записи хранятся только на устройстве.
- **Журнал уроков с устазом**: что сдано, оценка, замечания; аяты с замечаниями попадают в слабые места.
- **Поиск по тексту**: по слову из перевода или по арабскому слову.
- **Управление с экрана блокировки и наушников**: пауза, следующий и предыдущий аят.
- **Тафсир удобнее**: длинные толкования свёрнуты; выделенный фрагмент добавляется в конспект суры.
- **Прогресс суры на главной**: полоса — выученное зелёным, сегодняшний блок золотым.
- **Путь**: медальоны всех 30 джузов и вехи (первая сура, джуз, 5 %…, серии дней). Дату любой вехи можно изменить или отметить вручную.
- **Суры по джузам** с прогрессом каждого джуза и сворачиванием.

### GitHub Pages и офлайн
Загрузите в репозиторий всё содержимое папки (включая `sw.js`, `manifest.webmanifest`, `static/icons/`).
После первого открытия сайта приложение работает без интернета. Чтобы установить: в браузере телефона — меню →
«Добавить на главный экран» (на iPhone: «Поделиться» → «На экран „Домой“»). Однофайловая версия `dist/hifz.html` офлайн-режим не включает.

## Как запустить

**С Python (рекомендуется).** Нужен Python 3.8+, сторонние библиотеки не нужны.
```
python server.py
```
Откроется http://localhost:8765. Прогресс хранится в `data/progress.json`, тафсир кэшируется в `data/cache/`.

**Без Python.** Откройте `dist/hifz.html` двойным щелчком. Прогресс хранится в браузере —
делайте резервную копию в «Настройки → Данные».

**GitHub Pages.** Загрузите `dist/hifz.html` в репозиторий под именем `index.html` и включите Pages.
Работает всё, кроме хранения прогресса в файле (он будет в браузере).

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка приложения |
| `static/style.css` | оформление |
| `static/app.js` | логика: шаги, диапазоны, блоки, повторы, манзиль, аудио, тафсир, настройки |
| `static/blocks.js` / `blocks.py` | расчёт смысловых блоков (одинаковая логика на JS и Python) |
| `static/data.js` | справочник сур, джузов и чтецов |
| `static/data/quran.js` | встроенный текст и перевод (создаётся скриптом) |
| `static/data/themes.js` | тематическое деление сур на блоки с описаниями |
| `static/fonts/UthmanicHafs.ttf` | шрифт мусхафа |
| `source/quran.json` | исходные данные Корана |
| `tools/prepare_data.py` | проверяет исходные данные и создаёт `static/data/quran.js` |
| `server.py` | локальный сервер: прогресс в файл, кэш тафсира |
| `build_single.py` | собирает всё в один файл `dist/hifz.html` |

После изменений в исходниках: `python tools/prepare_data.py`, затем `python build_single.py`.
Проверить деление на блоки: `python blocks.py 74` (номер суры, размер, диапазон аятов).

## Важно

- Автоматические блоки — подсказка, а не тафсир: сверяйте границы с тафсиром и поправляйте.
- Тафсир и аудио берутся из интернета. Без связи текст, перевод, блоки и повторы работают, а тафсир и аудио — нет.
- Перевод Кулиева и русский перевод тафсира защищены авторским правом. Для личного использования это нормально;
  для публичного или платного распространения проверьте права.
